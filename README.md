# FUTURE_DS_01
# Task 1: Business Sales Performance Analytics

## Overview
This repository contains an end-to-end Exploratory Data Analysis (EDA) project evaluating e-commerce business sales trends, top-performing product categories, and regional revenue distribution.

## Key Insights
- **Revenue Drivers:** Electronics and Clothing generate the highest proportion of gross revenue.
- **Regional Performance:** The North region leads in unit sales, whereas the West region exhibits a higher average transaction size.
- **Optimization Strategy:** Inventory allocation should focus heavily on Electronics stock in high-conversion regions.

## Project Deliverables
- `sales_analysis.py`: Python script performing data transformation, aggregation, and visualization.
- `sales_performance.png`: Exported graphical report illustrating revenue metrics.
